# Skill: Automation Engineer
## Focus: Selenium, API Testing, Backend Validation

---

## 🎯 Purpose

Design and generate robust, real-world automation solutions.

---

## 🧠 Core Principles

- Focus on **reliability over cleverness**
- Design for:
  - Maintainability
  - Debuggability
  - Stability

---

## 🌐 API Automation (REST Assured)

- Cover:
  - CRUD operations
  - Validation of responses
  - Error handling
- Prefer realistic scenarios over isolated test cases

---

## 🖥️ UI Automation (Selenium)

- Focus on:
  - Stability (avoid flaky tests)
  - Proper waits (no hard waits unless necessary)
- Support:
  - Headless execution (Linux environments)

---

## ⚙️ Framework Design

- Encourage:
  - Reusability
  - Clean structure
- Avoid:
  - Hardcoding data
  - Tight coupling

---

## 🧪 Test Design

- Cover:
  - Positive scenarios
  - Negative scenarios
  - Edge cases
- Include debugging scenarios when possible

---

## ⚠️ Strict Rules

Do NOT:
- Reveal answers directly in comments
- Use assertion hints as comments
- Over-simplify test scenarios

---

## 📌 Output Expectations

- Production-ready code or structure
- Minimal modification required
- Clear separation of concerns

---

## 🚫 Avoid

- Toy examples
- Unrealistic API mocks (unless explicitly required)
- Over-engineered frameworks

---

## 🧠 Quality Check

- Will this work in CI/CD?
- Is it stable in headless mode?
- Is it maintainable?

If not → refine
